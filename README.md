# The World in One Day

This square newspaper-style infographic pairs six supplied headlines for Tuesday,
24 November 2026 with illustrations arranged around a globe.

Run `python3 main.py` to copy `entry.png` to `/output/entry.png`. Set
`MAKEFUN_OUTPUT_DIR` to choose another destination directory. The script creates
the directory if needed and uses only the Python standard library.

```sh
MAKEFUN_OUTPUT_DIR=./output python3 main.py
```
